# 🚀 NODUS — CRM Integrator Website & Interactive Calculator

Официальный сайт и онлайн-калькулятор CRM-интегратора **NODUS** (AmoCRM, Bitrix24, Wazzup24, Sipuni).

## 🌟 Возможности:
- 📱 Полная адаптивность (Desktop, Tablet, Mobile)
- 🌓 Переключатель тем (Dark / Light mode с мягкой палитрой)
- 🧮 Интерактивный реактивный 4-шаговый калькулятор со всеми тарифами
- 💼 12 реальных кейсов клиентов в интерактивном Lightbox
- ⚡ Смета в реальном времени и фиксация заявок

## 🚀 Деплой:
- **GitHub Pages:** Settings -> Pages -> Deploy from branch `main`
- **Railway / Vercel:** Импорт репозитория из GitHub
